Integritet

Vad Avtalsslut samlar in

Ingenting. Webbplatsen har inga formulär, inga konton, inga kakor, ingen statistik och ingen spårning, och den hämtar inga resurser från andra webbplatser. Länkar till andra webbplatser, till exempel TED, öppnas först när du klickar på dem.

Webbhotellet

Webbplatsen är statiska sidor på GitHub Pages. Som för alla webbplatser registrerar webbhotellet tekniska uppgifter om besök, bland annat IP-adresser, för drift och säkerhet. Det sker hos GitHub enligt GitHubs integritetspolicy; Avtalsslut tar inte emot eller lagrar de uppgifterna.

Innehållet

Sidorna visar uppgifter om offentliga upphandlingar som EU publicerar i TED: köpande organisation, vad som upphandlats, kategori, län och vilket kvartal avtalsperioden löper ut. Leverantörer visas inte med namn. Annonser i TED kan innehålla personuppgifter, till exempel namn på enskilda näringsidkare och kontaktpersoner; sådana uppgifter visas inte här och tas bort ur de texter vi skriver, och varje sida kontrolleras innan den publiceras.
